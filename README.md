## The job title

> Professional Mourner for Strangers' Goldfish Funerals

Fifty-three characters. A real-sounding job — professional mourning is a
genuine occupation — with one hilariously specific twist: the deceased are
strangers' goldfish. It lands on the first read, pictures instantly (a
hired mourner in black, weeping over a flushed goldfish), and is stranger
than ordinary work without ever becoming random word salad.

## How it works

`main.py` is deterministic and offline (standard library only). It writes
the single title above to the harness output path (`/output/entry.txt`,
or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set) and keeps a local copy of
`entry.txt` next to itself on a best-effort basis.

```sh
python3 main.py
```
